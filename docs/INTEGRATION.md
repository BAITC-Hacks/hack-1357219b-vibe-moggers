# Проверка интеграции Qadam — 23 сентября 2026

Frontend по умолчанию использует Go API через Vite `/api` → `127.0.0.1:8080`.
PostgreSQL запускается через `backend/docker-compose.yml` на порту 5433.
Инструкция запуска — в корневом README. Для отдельного браузерного демо
нужно явно установить `VITE_DATA_MODE=demo`; ошибки сервера не включают демо автоматически.

- `TEST_DATABASE_URL=... go test ./... -count=1 -timeout=90s`: все пакеты проходят,

- `go vet ./...` и `go build ./...`.

  Business / Team Beta, отправка предложения и сохранение после перезагрузки,
  выбор команды, передача результата и подтверждение этапа.
- Гостевой каталог получает публичные снимки без приватного описания задачи.
- AI-чат не получает чужой приватный черновик: проверка в PostgreSQL-тесте.
- Недоступный AI возвращает 503; frontend сохраняет описание и предлагает ручное заполнение.
- Строгий UX-аудит и `git diff --check` без замечаний.

## AI: реализовано, граница проверки

Go содержит `/api/ai/analyze`, `/api/ai/chat`, `/api/ai/transcribe`.
Чат использует Responses API, голос — Audio Transcriptions API. Ключ хранится
только в окружении backend. Голос ограничен 15 MiB; формат проверяется по сигнатуре,
запись не сохраняется. Поддерживаются WebM, MP4/M4A, Ogg, WAV.
Тесты проверяют запросы к локальному HTTP-имитатору провайдера, успешные ответы,
некорректные записи и роли, недоступность AI и отсутствие утечки ответа провайдера.

После настройки локального ключа проверены реальные запросы OpenAI:

1. `go run ./cmd/check-ai`: `gpt-4.1-mini`, `mode=live`, четыре вопроса, около 4 секунд.
2. Разные описания магазина и школы дают разные релевантные вопросы.
3. `assemble` возвращает значения с проверяемыми цитатами из источников.
4. В Chromium: описание → реальные вопросы → ответы → AI-карточка → сохранение
   черновика в PostgreSQL. Неподтверждённое предложение модели было отброшено.
5. Чат через Go API ответил с контекстом опубликованной задачи.
6. Русская синтетическая WAV-запись успешно расшифрована через Go и OpenAI.

Казахская синтетическая запись дала ошибки на нескольких моделях; полноценная
проверка живой казахской речи не завершена и отложена по приоритетам демонстрации.
Тест аудиофайла не заменяет проверку физического микрофона на устройстве жюри.
Ключ не включён в репозиторий. `AI_MODE=live` и выбранная модель распознавания
настраиваются локально; шаблон окружения сохраняет режим без обязательного ключа.

Это проверка локального MVP. Продакшен-аутентификация не входит в объём;
`X-Demo-Actor` остаётся демонстрационным переключателем, API слушает loopback.
