# hack-1357219b-vibe-moggers
Hackathon team repository for Vibe Moggers

## Qadam — от бизнес-потребности к работе со студенческой командой

Рабочая концепция для кейса AI Sana: AI помогает бизнесу уточнить задачу,
прозрачный рейтинг показывает её готовность, а открытый каталог связывает
задачи со студенческими командами. Окончательное решение принимает бизнес.

**Текущий статус: frontend реализован в `frontend/`.** Работает полный локальный
демо-сценарий с сохранением в браузере. Подготовлен REST-адаптер для Go;
интеграция с реальным backend и live AI требует его адреса и совместимого контракта.

## Запуск frontend

Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Нужен Node.js 22.12+ или совместимая современная версия;
сборка проверена на Node.js 25.4.0. Для демонстрации AI-ключ не требуется.

```bash
npm test
npm run build
```

[Инструкция frontend](frontend/README.md) · [Контракт для Go-разработчиков](frontend/API-CONTRACT.md).

Команда: один frontend-разработчик Vue и два backend-разработчика Go.
Стек: Vue 3 + TypeScript + Vite, Go `net/http` + `database/sql`, PostgreSQL,
pgAdmin, OpenAI Responses API с явным fallback. SQLite больше не используется.

Настоящая аутентификация не входит в эту версию: переключатель участника — демо-режим.
Баллы в локальном демо считаются в браузере, в API-режиме публичная оценка берётся
из подтверждённого снимка, возвращённого Go. Синтетические данные не являются
реальными клиентами или измеренными бизнес-результатами.
