# hack-1357219b-vibe-moggers
Hackathon team repository for Vibe Moggers

## Qadam — от бизнес-потребности к работе со студенческой командой

Рабочая концепция для кейса AI Sana: AI помогает бизнесу уточнить задачу,
прозрачный рейтинг показывает её готовность, а открытый каталог связывает
задачи со студенческими командами. Окончательное решение принимает бизнес.

**Frontend подключён к Go API и PostgreSQL.** API используется по умолчанию.
Роли, каталог, черновики, подтверждение, публикация, отклики и результаты работают
с базой данных. AI-вопросы, чат и голос требуют серверного OpenAI-ключа.

## Запуск всего проекта

Нужны запущенный Docker Desktop, Go 1.23+ и Node.js 22.12+.
Из корня репозитория, в первом терминале:

```bash
cd backend
docker compose up -d postgres
cp -n .env.example .env
# В редакторе: OPENAI_API_KEY=<ваш ключ>, AI_MODE=live
go run ./cmd/seed
go run ./cmd/api
```

Ключ хранится только в игнорируемом Git файле `backend/.env`.
Без ключа оставьте `AI_MODE=fallback`: данные и ручной сценарий доступны,
AI-запросы возвращают понятную ошибку без поддельной генерации.
После изменения `.env` перезапустите Go. Проверка API: http://127.0.0.1:8080/api/health.
Во втором терминале запустите frontend по инструкции ниже.

## Запуск frontend

Из корня репозитория:

```bash
cd frontend
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Нужен Node.js 22.12+ или совместимая современная версия;
сборка проверена на Node.js 25.4.0. Vite направляет `/api` к Go на порту 8080.
Для отдельного браузерного демо установите `VITE_DATA_MODE=demo` в `frontend/.env`.

```bash
npm test
npm run build
```

Команда: один frontend-разработчик Vue и два backend-разработчика Go.
Стек: Vue 3 + TypeScript + Vite, Go `net/http` + `database/sql`, PostgreSQL,
pgAdmin, OpenAI Responses API и Audio Transcriptions API. SQLite больше не используется.

Настоящая аутентификация не входит в эту версию: переключатель участника — демо-режим.
Баллы в локальном демо считаются в браузере, в API-режиме публичная оценка берётся
из подтверждённого снимка, возвращённого Go. Синтетические данные не являются
реальными клиентами или измеренными бизнес-результатами.
